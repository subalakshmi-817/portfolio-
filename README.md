- Live-style status panel with animated skill metrics
- Scrolling tech-stack ticker

## Running Locally

No build step required — it's a single static file.

```bash
git clone https://github.com/subalakshmi-817/portfolio-.git
cd portfolio-
```

Then open `index.html` directly in your browser, or serve it locally:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000` in your browser.

## Deployment

Hosted via **GitHub Pages** directly from this repository's `main` branch.

To deploy your own changes:
1. Push updates to `index.html` on the `main` branch.
2. GitHub Pages will automatically rebuild and publish the site within a few minutes.
